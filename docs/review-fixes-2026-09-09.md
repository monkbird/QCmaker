## 额外修复

- 百分比与缺失值同时处理时，固定按删除→转换→填补执行，避免出现 `[0.9,"90%"]` 混合单位。
- `.xls` 后缀伪装的压缩工作簿同样执行解压体积检查。
- 保存失败时不提前发布研讨事件序号；服务端回放同一事件会重新尝试持久化。
- 数据内容与向导快照、研讨事件与确认序号分别在同一 IndexedDB 事务保存。
- 异步结果捕获项目/课题/数据上下文，切换后拒绝旧任务写入新项目。
- 本地先保存会话但 start 尚未到服务器时，resume 不存在可回退 start。
- StrictMode 不重复执行恢复上传；失效下载结果、丢失图片、旧版不明来源成果不被继续采用。
- 未完成会话也登记到项目清理范围，避免事件遗留。
- 配置安全限制保留正常使用：允许切换已绑定凭据的服务商；自定义服务模型列表采用已保存地址；本地模型配置不再写入外部模型地址字段。
- 不完整角色分工返回错误，不再悄悄丢弃；保存凭据按钮恢复紧凑宽度。
- pytest 在导入应用前隔离配置，清理角色/凭据环境，重置 RAG 缓存并阻断真实外部 TCP，避免测试意外使用真实账户。
- 模型连通性测试纳入预算；发出请求后超时或崩溃仍保留待核对费用。

## 仍需明确的运行边界

1. 未使用真实付费供应商进行联调，因此不承诺所有供应商、套餐及模型协议完全一致。
2. 保留LangChain Community/Chroma兼容回退的弃用提示；本次未进行大范围依赖升级。
3. 文件解析采用输入/解压/行列与并发上限，未新增可强制终止的独立解析进程；任意自定义PPT模板未穷举渲染。
4. 默认本地、可信使用者模型；共享API令牌不是多租户权限系统。
5. 历史无项目归属的知识库资料保留但不自动猜测所属项目，需重新上传到明确项目；旧版不能证明来源的成果需要重新生成。
6. 数据表不提供任意单元格编辑，成果页不提供实际PPT逐页在线渲染；已按报告建议明确文档和界面措辞。
