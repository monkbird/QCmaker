# QCmaker 管理后台 · 第一版交互预览

本预览用于确认视觉与交互，不代表正式功能已经实施。所有数据均为内置演示数据；不请求业务 API，不读写数据库、配置文件或实际成果。

## 打开

当前预览地址：<http://127.0.0.1:52992/>。

服务未运行时，在项目目录启动：

```powershell
python -m http.server 52992 --bind 127.0.0.1 --directory D:/Program/work/QCmaker/docs/admin-console-preview
```

也可直接用浏览器打开本目录 `index.html`。运行时不依赖构建工具或外部组件库。仅点击“设计参考”时加载原作公开图片。

## 本版可检查内容

- 12 个管理模块及登录页：总览、用量、预算、数据集、研讨、成果、知识库、日志、系统状态、配置、安全、审计。
- 玻璃侧栏展开/收起、功能搜索、手机菜单、时间范围切换。
- 表格搜索与状态筛选、空态、详情抽屉、通知抽屉。
- 输入目标编号的删除确认、会话结束/恢复、预算调整和演示审计。
- 项目文档与清空流程、会话吊销、模型探测确认、维护结果。
- 演示配置保存、全历史用量 CSV 导出。

页面始终注明演示状态。敏感凭据流程只做说明，不要求输入真实密码或令牌；成果下载说明尚未接入文件，不制造虚构 PPT。演示配置请勿输入真实密钥。

刷新或点击“重置演示”恢复初始数据。数据变更仅在当前页面内存中存在。

## 视觉依据

参考：[Glassmorphism Dashboard / Miguel Ángel Avila](https://dribbble.com/shots/26136889-Glassmorphism-Dashboard)。

本次已查看原作，提取的具体特征：近黑背景、蓝青到淡紫的局部光晕；可透见背景的侧栏；深色顶部栏；白色局部光学边缘；内凹搜索框；立体圆形控件；窄条高亮选中态。将该侧栏语言扩展至看板卡片、表格、抽屉与弹窗，中文内容和业务结构为 QCmaker 定制。

此处为手工编写的 HTML/CSS/JS 原型，并非参考作者的源码，也未把原作图片当成产品界面。正式前端仍按 v2.0 方案使用现有 React/AntD/ECharts，实现前须先确认本预览。

已按预览批注调整：移除左上三个彩色圆点；左右顶栏统一为 48px 并对齐；加强面板分层投影、边缘高光以及输入框的内凹阴影。以上用户反馈优先于原作中的对应装饰。

详细视觉约束与批注记录见 [design-spec.md](design-spec.md)。
