## 视觉规则

- 背景：近黑底色 `#02040d`，蓝青光晕集中在左上至中央，淡紫光落于下方；右侧保留暗部，使前景层次可见。
- 外壳：侧栏与内容区为分离的玻璃面板，桌面间距 20px、圆角 23px；由背景透色形成材质，不使用大面积纯色填充覆盖光晕。
- 顶栏：统一 48px；侧栏顶部接近黑色，右侧顶部延续玻璃层；边界阴影保持水平一致。
- 卡片：较薄玻璃层，16px 圆角；指标卡为 14px；亮边位于左上，暗边及投影落于右下。
- 控件：搜索框内凹，主按钮微凸；选中项保留窄白色发光标记；图标使用细线条，避免混用多套图标风格。
- 阴影：外壳、内容卡片、按钮分层设置；不能仅通过统一加黑背景来模拟层次。
- 文本：中文正文保持清楚，白色主信息配蓝灰色次信息；不得对文字施加整体模糊。玻璃效果仅作用于背景和边缘。
- 图表：清浅蓝主线、淡紫次线与低透明度面积填充；网格弱化，交互信息保持清晰。
- 抽屉与弹窗：同一套玻璃边缘与暗部阴影，背景遮罩适度模糊；危险操作明显区分，并要求目标确认。

精确样式以 `preview.css` 为当前基线。正式 React/AntD 实现应提取共享 tokens，并逐组件覆盖材质，避免恢复为组件库默认平面样式。

## 响应式与验证

- 1440px：展开侧栏、六项指标同排、主要内容分两栏。
- 768px：收窄导航、指标三列、内容纵向排列。
- 390px：菜单抽屉、指标两列、表格内部横向滚动；页面本身无横向溢出。
- 保留键盘焦点、Escape 关闭弹窗、系统减少动画偏好和不支持背景模糊时的回退。
