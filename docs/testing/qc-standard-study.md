## 2. 标准定位：先判定项目类型

第6-7页“总则”规定活动遵循“全员参与、领导作用、持续改进、基于客观事实、应用统计方法”的原则，并以 PDCA（Plan、Do、Check、Act）循环组织活动。第9页定义：问题解决型课题是针对已经发生的、通过调查能够找到现场存在的问题而选择的课题；创新型课题是运用新思路、新产品、新方法、新设备等选择的活动课题。

本项目目标是调教“自定目标问题解决型”各章节顾问，因此默认走第4.1节流程，不套用创新型第4.2节流程。标准的流程图证据在第10页图2，问题解决型依次为：选择课题→现状调查→设定目标→目标可行性论证→原因分析→确定主要原因→制定对策→对策实施→效果检查→制定巩固措施→总结和下一步打算。注意，“目标可行性论证”只对指令性课题设置；第11页注释明确自定目标课题没有该步骤。

## 3. 自定目标问题解决型：硬要求与顾问输出规则

下表中的“硬要求”是标准正文明确提出的要求；“顾问规则”是产品应执行的可操作检查；“不属于硬要求”专门列出不能冒充标准的惯用做法。

|章节|标准硬要求（证据页）|顾问可执行规则|不能误写成标准硬要求的内容|
|---|---|---|---|
|选择课题|课题来源有三类：指令性、指导性、自选性（第10页4.1.2.1）；自选时可从实际组织管理、提高效率/降低成本/保证安全和提高质量等关键点、一段时期或外部顾客/相关方要求选择（第10页）。选择要求：小组能力范围内；与小组成员直接相关且有数据；课题名称应明确表达问题（第10页4.1.2.2）。|必须保存课题来源、问题对象、数据依据和课题名称。自定目标课题不得将上级硬指标伪装为小组自定目标。课题名应直接写“提高/降低/缩短……”，不能只写“加强管理”“提升水平”。|没有条文要求必须使用某一种选题评分表、必须列若干备选课题或必须写“必要性、迫切性、可行性”固定三项。可作为论证材料，但需标为项目惯例。|
|现状调查|应进行现状调查；数据和信息应具有客观性、全面性、时效性、可比性；对数据和信息进行分层整理和分析；通过调查明确问题症结、掌握现状程度，为目标设定和原因分析提供依据（第11页4.1.3）。|必须有调查期间、对象/样本、数据来源、分层维度、统计口径和结论。结论要回答“问题在哪里、程度多大、主要表现是什么”，并能向目标和原因分析传递证据。|标准没有规定必须使用柏拉图、饼图、柱状图或必须抽取多少样本；第15页附录A只是统计方法推荐表，不是每个课题的强制图表清单。|
|设定目标|活动目标要与课题一致并明确改进程度。自定目标来源可为小组成员共同制定的目标；目标设定可考虑上级/下达指标、顾客要求、同行业先进水平、组织曾经达到的最好水平、现状调查症结及预期达到水平（第11页4.1.4.1-4.1.4.2）。目标要求：与活动内容一致、目标可测量可检查、目标具有挑战性（第11页4.1.4.3）。|目标必须有指标、单位、基线、目标值、完成时限/统计区间，并能由活动记录复核；目标值要能由现状调查或依据说明支撑。自定目标课题不强制写“目标可行性论证”章节。|“目标必须提高30%”“必须采用SMART”等不是本标准原文要求；目标值的比例、样本量、图形类型不能凭空生成。|
|目标可行性论证|仅指令性课题要求设置目标可行性论证；可从同行业先进水平、组织能力可达到水平、现状调查症结等方面论证，证明目标可实现并明确实现路径（第11页4.1.5）。|对自定目标项目默认标记为“不适用（标准注释：自定目标课题无此步骤）”；若用户材料仍提供论证，可作为补充证据，不能把它升级为硬性章节。|不能要求所有问题解决型课题都必须有目标可行性论证。|
|原因分析|原因分析应针对问题症结的直接原因；原因之间逻辑关系应清楚；可从人、机、料、法、环、测等方面考虑，系统展示末端原因，避免遗漏；每一末端原因应落到末端，以便直接采取对策（第11页4.1.6）。|应从“现状调查结论”出发画/列因果链；每个末端原因都要能被后续确认和转化为对策。顾问应拒绝只有一级大类、只有口号、没有末端原因的分析。5M/6M仅作分析视角提示，是否采用及采用多少维度应由事实和课题决定。|标准没有规定必须恰好使用“5M”、每类必须列1-3点、必须固定画鱼骨图。人机料法环测不是数量模板，也不是逐类覆盖的硬门槛。|
|主要原因确认|应收集全部末端原因，识别并排除超出小组能力范围的原因；对末端原因逐一依据数据和事实，客观确定主要原因（第11页4.1.7；第12页4.1.7 a-c）。确认方法为现场调查、现场验证和测量分析（第12页4.1.7 d）。必要时制定要因确认计划，并根据末端原因症结影响程度判定是否为主要原因。|必须给出末端原因清单、是否属于小组能力范围的判断、确认方法、判定指标/阈值、数据或现场记录、判定结论。优先使用现场调查、验证、测量分析；不能只凭小组投票、专家意见或“经验判断”定要因。|标准没有规定要因必须确认几个、每类1-3个、必须使用现场试验或必须通过“真因/非真因”固定表格；这些可为组织模板。|
|制定对策|应针对主要原因制定对策；必要时，针对主要原因提出多种对策，并用客观方法进行评价和选择；按5W1H制定，对策要有明确目标、可测量可检查、措施具体（第12页4.1.8）。5W1H含义：What对策、Why目标、Who负责人、Where地点、When时间、How措施（第12页注释）。|每项对策必须能回指主要原因，写清目标值/验收口径、责任人、地点、时限、具体措施；存在多种候选对策时留下客观比较和选择依据。|标准没有规定必须采用打分法、矩阵法、经济性/可行性/有效性三项固定权重，也没有要求每个主要原因必须只制定一项对策。|
|对策实施|应按对策表逐项实施并与对策目标比较，确认对策效果；未达到目标时应修改措施并实施新措施；必要时验证实施对安全、环境、成本、相关方等的负面影响（第12页4.1.9）。|实施记录要逐项对应对策，保留日期、责任人、现场证据、实施结果和目标比较；未达标必须形成调整措施和再次验证记录。涉及安全、环境、成本、相关方时增加影响验证。|标准没有要求固定实施周期、固定照片数量或固定整改闭环表样式。|
|效果检查|对策实施完成后检查：课题目标是否完成；与对策实施前现状比较改进程度；必要时确认活动产生的经济效益和社会效益（第12页4.1.10）。|必须同时呈现目标值与结果值、实施前后同口径对比、改进程度及结论；经济/社会效益在“必要时”提供计算口径和证据，不能用未经核算的金额代替。|标准没有规定经济效益必须达到某金额、必须使用某种统计检验或必须制作某类效果图。|
|巩固措施|应将经实施证明有效的措施纳入有关标准、制度（如工艺标准、作业指导书、管理制度、人员培训制度等），并经有关部门批准；必要时跟踪巩固措施实施效果（第12页4.1.11）。|必须写明有效措施、转化文件/标准、批准部门或状态、执行与培训/跟踪证据；“已推广”应有相应的标准、制度或实施证据，文件编号可作为证据但不是本条明文硬要求。|标准没有规定巩固期必须30/60/90天，也没有规定必须建立多少项制度或必须提供文件编号。|
|总结和下一步打算|应回顾、总结活动全过程，找出不足；从专业技术、管理方法、小组成员综合素质等方面总结；提出下一次活动课题（第12页4.1.12）。|总结应分别回答技术、管理、成员能力三类收获与不足，并给出下一课题或方向；下一步用事实和计划表述，不承诺标准未要求的结果。|标准没有规定下一课题必须与本课题同一专业、必须写固定口号或必须承诺“全年/度汛”结果。|

## 4. 5M/6M、图表和数量偏好的边界

1. 标准正文第11页4.1.6 c明确要求从“人、机、料、法、环、测”等方面考虑末端原因。顾问应把它实现为“覆盖检查项”，而不是自动生成每类若干原因。材料不足时宁可标记“该维度尚无证据”，不能为了凑满鱼骨图编造原因。
2. 每类1-3点、固定五大类、固定三层因果链、固定一张鱼骨图/柏拉图，均未在所核验标准正文中发现。它们可作为成果书可读性模板或项目方偏好，必须标注为“惯用偏好/模板约束”，不能报成 T/CAQ 10201-2020 的硬要求。
3. 第15页附录A给出活动过程与统计方法的对应关系：选择课题可用头脑风暴、水平对比、分层法、排列图等；现状调查列有分层法等；原因分析列有头脑风暴、因果图、关联图、系统图、排列图等；确定主要原因、制定对策、效果检查、巩固措施等也有推荐统计方法。附录A是“推荐使用关系”表，不能推导出每课题每图必须使用。
4. 图表必须服务于客观、全面、时效、可比的数据要求。没有数据来源、样本口径和时间范围的图表，即使形式齐全，也不足以满足第11页4.1.3的实质要求。

## 5. 顾问输出应内置的判定项

每一章节顾问至少输出以下字段，字段是实现建议，不宣称为标准原文格式：

- `standard_basis`：标准条款号、页码、硬要求摘要或“不适用”；
- `evidence_required`：应由用户材料提供的事实、数据、记录、图表或批准文件；
- `current_facts`：材料中已找到的证据，找不到就写“未知/未提供”；
- `compliance`：满足、部分满足、不满足、不适用、无法判断；
- `issues`：缺口必须具体到指标、口径、责任人、时限、记录或逻辑链；
- `suggestion`：只补结构和表达，不替用户编造数字、日期、样本、原因或效果；
- `source_locator`：如“标准第11页4.1.3”。

对自定目标问题解决型，顾问流程应硬编码以下两项判断：

- 目标来源判定为“自定目标”时，目标可行性论证章节标记“不适用”，同时检查第11页注释，不因模板存在而判缺项。
- 课题若被写成“创新型”，应转用第13-14页4.2流程，不能继续使用问题解决型的现状调查、原因分析和要因确认要求；本项目当前研究范围不展开创新型章节。

## 6. 评分附录的使用限制

第16-18页附录B是现场确认和成果评价参考。问题解决型成果评价在第17页列出：选择课题15分、原因分析/确定主要原因30分、对策制定/实施20分、效果20分、成果推广5分、特色10分，共100分；第16页还列活动过程、活动效果、成果巩固与推广、综合素质等现场确认项目及分值。附录B可用于顾问的风险提示和评审准备，但不能反向创造正文硬要求；例如评分项出现“统计方法应用合理、正确”，仍应回到正文第6页总则和第11-12页具体条款判断，不能自行增加标准没有写出的固定数量门槛。

## 8. 结论：给产品/顾问的精确执行口径

顾问应先判定“自定目标问题解决型”，再按第10-12页的 10 个适用环节给出逐节证据审查；将“目标可行性论证”明确标为不适用。审查重点是数据是否客观全面及时可比、目标是否可测量可检查且有挑战性、因果链是否落到末端原因、主要原因是否用现场调查/验证/测量分析逐一确认、对策是否按5W1H写成可执行措施、实施是否逐项对照目标并处理未达标情形、效果是否用同口径前后对比、有效措施是否经批准纳入标准制度、总结是否覆盖技术/管理/成员素质及下一课题。5M/6M和每类1-3点只能作为模板偏好或覆盖提示，不能作为标准硬门槛；未知数据、日期、样本、原因和效果必须保持“未知/未提供”，不得自动补写。
